# C2C Canvas Share

Obsidian plugin that shares a canvas as a read-only web page.

- Canvas menu (⋯) → **Share canvas on the web**: publishes the canvas and copies the link.
- **Copy canvas share link** and **Stop sharing canvas** appear once a canvas is shared.
- Settings → C2C Canvas Share → **Upload key**: paste the key from 1Password once.

Server source lives in the ClickToClose monorepo at `apps/canvas-share`.
